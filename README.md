# Music Neighboring Rights Royalty Recovery

Identify unmatched recordings and recover neighboring-rights royalties across performers, masters, societies, and territories.

**Primary buyer:** Labels, performers, and neighboring-rights administrators. **Evidence:** recording metadata, performer lineups, ISRCs, airplay, simulcast, public performance, territory rules, society statements, claims, and payments.

Full local application built with React, Vite, Express, PostgreSQL, and OpenRouter. Includes 15 domain-specific capabilities, 105 custom AI workbench fields, three scenario-fill controls per feature, operational registers, workflow transitions, analytics, professional AI decision briefs, audit history, and at least 15 PostgreSQL records per capability.

## Domain capabilities

- Recording metadata registry
- ISRC normalization
- Performer lineup evidence
- Rights ownership mapping
- Airplay usage ingestion
- Public performance matching
- Simulcast usage control
- Territory eligibility rules
- Featured performer allocation
- Non-featured performer allocation
- Society statement matching
- Unmatched usage claim
- Society query workflow
- Cash reconciliation
- Recording territory analytics

Run `./start.sh`, then open <http://127.0.0.1:4738>. API: `5738`.
